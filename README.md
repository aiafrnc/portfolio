# Mariah Franchesca Orca | Portfolio

React + Vite portfolio.

## Run locally
    npm install
    npm run dev

## Build
    npm run build

## Deploy on Vercel
Import the GitHub repo. Vercel detects Vite automatically (build: `npm run build`, output: `dist`).

Edit `src/data.js` to change your profile, projects, and skills. Put images in `public/images`.
